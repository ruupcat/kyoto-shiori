# 京都・奈良・和歌山 旅のしおり

2026年11月14〜19日、京都・奈良・和歌山旅行の第1段階プロトタイプ。外部ライブラリ・フォント・APIを使わない静的HTML/CSS/JavaScriptです。

## PCで確認

このフォルダーで `node preview.cjs` を実行して http://localhost:8765/kyoto-shiori/ を開きます（Node.jsが必要）。HTMLの直接ダブルクリックではJSONの読み込みとPWAが動作しません。

## GitHub Pagesに公開

1. このフォルダーのファイルをGitHubリポジトリにアップロード（個人の旅程・宿泊住所を含むため、公開範囲を確認してください）。
2. Settings → PagesでDeploy from a branch、対象ブランチ、/(root)を選択。
3. 発行されたHTTPSのURLをiPhone Safariで開きます。

相対パスとService Workerのフォルダースコープを使うので、リポジトリのサブパスでも動きます。参加者はニックネーム・役割で表示し、朝食選択などの端末内データは端末内に保存します。

## オフラインで使う

Safariで公開URLを開き「保存完了」を確認 → 共有から「ホーム画面に追加」 → 追加したアプリをオンラインで一度起動 → 機内モードで閉じて開き直し、全日程・宿の詳細を確認してください。初回オンラインアクセスが必要です。地図の外部ページは保存対象外です。ブラウザーによって保存データが削除される可能性があるため、出発前に動作確認とバックアップを推奨します。

## 実装済み

- 全6日間の旅程、詳細開閉、参加者、別行動、固定予定、未定の区別
- 宿・店の住所、営業時間・電話欄、オンライン地図リンク
- 朝食A/B選択の端末内保存
- 朝食選択などの端末内データのJSONバックアップ・復元
- 全日程の印刷（印刷画面からPDF保存可能）
- PWA・アプリと初期旅程のキャッシュ・保存状態確認

## 次の段階

予定の自由編集・追加削除・並べ替え、交通時刻表の登録、次の便の検索、逆算・遅延計算、案内画像の保存は未実装です。バックアップ対象は朝食選択などの端末内データで、初期旅程はtrip.jsonで管理します。端末間の自動同期はありません。

旅行情報は提供された文章のみを使用し、施設・交通・山道の公式情報はまだ調査していません。不明な時刻や便は生成していません。2026年10月29日の更新内容を反映し、11/15〜17は宿に3泊、往復は夜行バスで車中泊、11/19帰宅としています。旅のメモ欄は削除しましたが、既存の保存メモはデータ互換のためバックアップ内に保持します。

## 更新

旅程は `trip.json` を編集し、`node build.cjs` でHTML内の初期データも更新します。日程表示は追加通信に依存しません。ファイル変更時は `sw.js` のCACHE末尾を次の版へ更新してください。通信があれば最新版を取得して保存し、通信失敗・2.5秒の待ち時間超過では保存済みファイルを使います。`node verify.cjs` でデータ一致・通信失敗時の初期表示・保存・オンライン更新後のオフライン起動を確認できます。
